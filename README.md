# Reel Rush - Movie Ticket Booking System
Reel Rush is a console-based Movie Ticket Booking System developed using Python and MySQL. The application allows users to browse movies, filter them by genre, select show timings, book seats, pre-order meals, simulate payments, and submit movie reviews.

Features:
  Browse available movies
  Filter movies by genre
  Book tickets for today or tomorrow
  Choose seats from different categories
    Classic
    Executive
    Recliner
  Automatic ticket price calculation
  Select show timings
  Choose seat categories (Classic, Executive, Recliner)
  Meal and beverage pre-booking
  Payment simulation using Card or UPI
  User review system
  
Technologies Used:
  Python
  MySQL

Database Setup:
The repository includes a complete database export file: database.sql 
Create a MySQL database named project and import the SQL file before running the application.
